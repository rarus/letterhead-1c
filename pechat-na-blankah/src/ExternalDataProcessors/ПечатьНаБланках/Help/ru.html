Общее описание

Инструмент обеспечивает пакетную печать данных из программ 1С на различных видах типографских носителей (бланки, анкеты и др.) и предназначен для автоматической подстановки данных из таблицы в заранее подготовленные шаблоны с последующей возможностью печати или сохранения готовых результатов.

Инструмент состоит из трех основных страниц, последовательно отражающих рабочий процесс:

·          бланк – для создания и редактирования шаблона;

·          данные – для ввода или загрузки таблицы с информацией для печати;

·          результат – для предварительного просмотра или правки сформированного документа перед печатью или сохранением.

Создание шаблона

На странице «Бланк» отображается табличный документ – область для проектирования шаблона будущего бланка. Здесь можно создать новый шаблон или загрузить уже готовый при наличии.

Для создания шаблона необходимо определить места для подстановки данных, указав в них имена полей в формате #СтолбецN. Имя поля должно начинаться с символа «#» (решетка) и соответствовать порядковому номеру столбца в таблице данных (начиная с 1). Инструмент ищет в шаблоне именно эти имена для автоматической подстановки данных.

Для оформления шаблона используются стандартные инструменты, с помощью которых можно изменять шрифт, расположение элементов, цвет фона, границ и текста, объединять ячейки, а также загружать картинки и фигуры.

Предусмотрена функция разделения копий бланков на отдельные страницы. По умолчанию эта опция активна: при формировании документа каждая новая копия бланка будет начинаться с новой страницы и печататься на отдельном листе. Если опция отключена, все копии будут напечатаны на одном листе, который затем потребуется разрезать.

Заполнение данных

На странице «Данные» отображается область ввода табличных данных, которые будут печататься на бланках. Таблица заполняется построчно: первый столбец соответствует полю #Столбец1, второй – #Столбец2 и т. д. Каждая строка представляет один заполненный бланк. Столбцы не имеют заголовков-идентификаторов.

Важно! Если исходный файл содержит заголовки столбцов, их необходимо удалить перед печатью. Данные обрабатываются с первой строки и распознаются по порядковым номерам колонок. Таблица должна содержать исключительно подставляемые значения.

Форматирование ячеек (шрифт, цвет, размер и прочее) на странице «Данные» не учитывается. Оформление задается на этапе создания шаблона.
